自律的とは、一人で抱え込むことではありません

目的・期限・権限の範囲を理解し、自分で判断することと、相談すべきことを見極め、周囲と連携しながら進めること。それが本スクールで扱う「自律的に仕事を進める」です。条件が変わった場合には、早めに共有し、対応方針や期限を再合意することも含みます。

  • 仕事の目的・期待成果・完成基準を確認する
  • 事実と推測を分け、必要な情報と制約を整理する
  • 手順・優先順位・確認のタイミングを設計する
  • 自分の案と理由を添えて相談し、関係者とすり合わせる
  • 計画とのずれを早く捉え、共有・調整する
  • 期待を満たしたかを確認し、最後まで完了させる

Program 全5回のプログラム

各回2時間。第1〜4回の後に職場実践を行い、次回に振り返ります。以下はカリキュラム案です。

第1回

仕事の全体像をつかみ、
期待成果を確認する

Q.「この仕事は、誰のために、何を実現する仕事なのか？」

LEARNING POINTS
  • 目的・期限・完成基準の確認
  • 前後の仕事とのつながり
  • 自分で判断してよい範囲と相談条件
  • 「作業をする」と「成果をつくる」の違い

職場実践：現在任されている仕事を一つ選び、目的・期待成果・期限・関係者を整理する。不明点を上司や依頼者に確認する。

第2回

状況を整理し、進め方を組み立てる

Q.「何が分かっていて、何が足りないか。どの順序で進めるか？」

LEARNING POINTS
  • 事実・解釈・不明点の区別
  • 必要な情報と制約の確認・整理
  • 仕事を具体的な行動に分解する
  • 手順・優先順位・期限の設計

職場実践：第1回で選んだ仕事について、進め方・必要な情報・期限・チェックポイントを整理し、実行計画をつくる。

第3回

自分の考えを持ち、
関係者とすり合わせる

Q.「誰に、何を伝え、何を相談すれば仕事が前に進むか？」

LEARNING POINTS
  • 選択肢と判断理由の整理
  • 報告・連絡・相談の使い分け
  • 相手が判断・行動できる伝え方
  • 関係者への依頼と認識のすり合わせ

職場実践：実際の業務で、状況・自分の案・理由・判断してほしいことを整理して相談し、その結果を記録する。

第4回

実行・進捗を管理し、問題に対応する

Q.「予定どおりに進まないとき、どう判断し、どう働きかけるか？」

LEARNING POINTS
  • 進捗と問題の把握
  • 原因と対応策の検討
  • 早期の報告・相談
  • 計画の修正と再合意

職場実践：計画と進捗を照らし合わせ、ずれがあれば関係者に働きかけて修正する。ずれがなければ、起こりうる問題と備えを点検する。

第5回

成果を確認し、最後までやり切る

Q.「作業を終えたことと、期待された成果を実現したことは同じか？」

LEARNING POINTS
  • 完成基準との照合と完了報告
  • 経験からの学びの言語化
  • 複数スキルの統合
  • 条件の異なる総合ケースへの応用

職場実践：自分の仕事の進め方の変化と、今後継続する行動を整理し、上司と共有する。

【ケースについて】

継続ケースでは、部署の改善提案をまとめる仕事を任される場面を扱います。曖昧な依頼、情報不足、関係部署との調整、期限変更、成果物の修正といった場面で、必要な行動を選び、学んだ能力を使います。
（最終回には、条件の異なる総合ケースで応用します）

FAQ よくある質問

Q 報連相やロジカルシンキングの研修とは何が違いますか？
それぞれのスキルを学ぶだけでなく、一つの仕事を成果まで進めるために、いつ・何のために・どのように使うかを練習します。全体像をつかみ、必要な能力を磨き、総合ケースや自分の仕事で組み合わせて使う構成です。
Q 1日研修との違いは何ですか？
各回の間に職場実践を挟み、次回にその結果を振り返る点です。受講当日の理解だけで終わらせず、実際に使った際の課題をもとに改善する機会を設けています。
Q 自律的とは、上司に相談しないという意味ですか？
いいえ。自分で判断することと、相談・合意が必要なことを見極め、適切に周囲へ働きかけることも、自律的な仕事の進め方に含みます。
Q 職場実践には、どの程度の負荷がかかりますか？
現在任されている業務を題材に、確認・計画・相談・振り返りの方法を変えていただきます。別の業務プロジェクトを新たに課す設計ではありませんが、実践内容を記録し、振り返る時間は必要です。課題の目安時間は開催案内でお知らせします。
Q 上司には、どのような報告がありますか？
受講者ごとに、受講・課題への取り組み、研修内で確認できたこと、職場実践の状況、今後の育成ポイントを共有する予定です。報告頻度・形式・対応言語は確定後にご案内します。
Q 上司に必要な協力はありますか？
受講前に期待する行動と実践業務を共有し、期間中に本人が確認・相談できる機会を設けてください。研修後は個別報告を、次に任せる仕事や日常のフィードバックにご活用ください。
Q 他社の参加者に、社内情報を話す必要がありますか？
共通演習は架空ケースを使用する設計です。自分の実践を共有する際は、顧客名・個人名・価格などの機密情報を除きます。開示できない情報を共有する必要はありません。
Q 欠席時の補講・録画はありますか？
継続的な実践と振り返りを行うため、全回出席を基本とする予定です。欠席・補講・録画の取り扱いは、確定した受講規定でご案内します。
Q オンライン受講に必要な環境は何ですか？
カメラ・マイク付きのPC、安定した通信環境、討議に参加できる静かな場所をご準備ください。使用ツールと接続方法は、開催案内でお知らせします。
Q 開催日程はいつ決まりますか？
現在調整中です。確定次第、本ページを更新し、お申し込みフォームを公開いたします。先行してのご案内をご希望の場合は、下記のお問い合わせ先までご連絡ください。
