PROGRAM CONCEPT

“Break the Shell, Build the Future”

自社の常識（Shell）を破り、経営者としての視座を獲得する6ヶ月間の集中コース。

全6回 / 月1回・対面
対象：Director / GMクラス

ナショナルスタッフの経営幹部登用が進むなか、多くのインドネシア日系企業が同じ課題に直面しています。「現場を回す力」はあっても、「経営を担う視座」が育っていない――。

I-ESLPは、この課題に「実践的MBA」と「異業種他流試合」の2つで正面から応えるプログラムです。製造業に加え、商社・金融・ITなどビジネスモデルの異なる企業の経営幹部が同じ教室に集い、MBAのフレームワークを使って互いの事業を分析し、議論します。

社内では決して得られない視座と、業種を越えた経営者ネットワーク。その両方を6ヶ月で手にしていただきます。

Challenges 変革を阻む「3つの壁」

理想の経営者像（To-Be）に対し、ナショナルスタッフの経営幹部登用が進むなかで立ちはだかる課題です。

01 ｜ 視座の壁
Perspective Wall

「現場の最適化」には強いが、「経営全体の最適化」や「外部環境の変化」を見る視座が育っていない。いわゆる「井の中の蛙」の状態から抜け出せない。

02 ｜ 理論の壁
Literacy Wall

叩き上げゆえに、体系的な経営言語（戦略・財務・組織論）を持たず、本社や社外との高度な議論に入っていけない。

03 ｜ 関係性の壁
Network Wall

社内の人間関係は濃密だが、社外・異業種の経営層との接点が乏しく、新たな知見や刺激を得る機会がない。

▶ この3つの壁を、「他流試合」と「実践」によって突破します。

対面での月1回・全6回、異業種混成チームでの議論と自社課題への適用を通じて、
経営者としての視座・言語・ネットワークを同時に獲得します。

Features 本プログラムの特徴

異業種「他流試合」で、自社の常識を相対化する

身近な製造業に加え、ビジネスモデルの異なる商社・金融・ITなど、多様な業種の経営幹部が同じ教室に集まります。自社の「強み」が他業界からどう映るのかを相互にフィードバックし合うことで、社内では決して得られない視座と刺激を獲得します。

MBAフレームワークを「自社課題」に適用する

戦略・マーケティング・戦略会計・組織論といったMBAの体系的フレームワークを、インプットするだけで終わらせません。毎回、学んだ理論を自社の実課題に当てはめて考え抜き、経営判断の言語と型を体得します。

事前・当日・事後の3段階で、学びを行動に変える

基礎知識は事前課題でインプットし、当日は講師が「問い」を投げるファシリテーターとして異業種混成チームでの議論に集中。事後は「自社適用レポート」の提出を義務化し、他業界の知見を自社課題にどう応用するかを言語化します。

選抜制・少人数の対面スクール

公開型でありながら選抜制を採用。経営を担う覚悟のある方だけが集まる場だからこそ、議論の質が上がります。対面での実施により、6ヶ月を通じて業種を越えた経営者同士の強固なネットワークが形成されます。

導入企業様にとってのメリット

  • 「井の中の蛙」からの脱却：自社グループ以外の優秀な経営人材と議論することで、自社の常識を相対化できます。
  • 次期経営者候補の選抜・育成：5年後の経営者登用を見据え、経営者としての基礎体力と外部ネットワークを1年目で構築できます。
  • コストパフォーマンス：一社単独で講師を招聘するよりも、公開型にすることで、質の高い講師による研修を適正価格で受講いただけます。

Learning Model 学習モデル（Input-Output Cycle）

毎回のセッションを「事前 → 当日 → 事後」の3段階で設計し、学びを確実に行動へ変えます。

PRE-WORK

事前課題

基礎知識は指定資料で事前にインプット。貴重な講義時間を知識説明で浪費しません。

IN-CLASS

当日

講師は「問い」を投げるファシリテーター。異業種混成チームでのグループワークを重視します。

POST-WORK

事後課題

「自社適用レポート」の提出を義務化。他業界の知見を自社課題にどう応用するかを言語化します。

カリキュラム構成（全6回）

各回とも「MBA要素（Input）」と「他流試合ワークショップ（Output）」の2部構成で進行します。

方針：身近な「製造業」に加え、ビジネスモデルの異なる「商社」「金融」「IT」などを題材とし、思考の幅を広げます。

【Day 1】 日程調整中（2026年11月開講予定）

経営者の視座とリーダーシップ

MBA要素（Input）

リーダーシップ論 / ミッション・ビジョン / 経営者マインドセット

他流試合ワークショップ（Output）

【自社の常識を疑う】自社の「強み」が他業界からどう映るか、相互フィードバックを行う。

自社への適用視点

既存の「当たり前」を壊し、自社のあるべき姿を定義する。

【Day 2】 日程調整中

経営戦略と競争優位

MBA要素（Input）

外部環境分析（PEST / 3C） / SWOT分析 / 競争戦略（ポーター）

他流試合ワークショップ（Output）

【業界構造の比較】異業界の収益構造を比較し、自社の勝ち筋を再定義する。

自社への適用視点

グループ内の位置付けだけでなく、市場全体での競争優位性を再考する。

【Day 3】 日程調整中

マーケティングとイノベーション

MBA要素（Input）

STP分析 / バリュープロポジション / イノベーションのジレンマ

他流試合ワークショップ（Output）

【異業種イノベーション】他業界の成功事例（DX等）を自社に転用できないか、アイデア出しを行う。

自社への適用視点

「言われたものを作る」から脱却し、新たな価値を提案する視点を持つ。

【Day 4】 日程調整中

戦略会計と意思決定

MBA要素（Input）

財務三表の連関（PL / BS / CF） / 損益分岐点分析（CVP） / コスト構造（固定費・変動費）

他流試合ワークショップ（Output）

【ビジネスモデルの数字解読】「製造業（重資産）」と「商社・IT（軽資産）」の決算書を比較し、業界による利益の出し方やリスクの違いを読み解く。

自社への適用視点

単なる経費削減（PL思考）から、在庫や設備などの資産効率（BS思考）を意識し、利益を生み出す体質へ転換する。

【Day 5】 日程調整中

組織マネジメントと人材育成

MBA要素（Input）

組織行動論 / ダイバーシティ / 変革管理（チェンジマネジメント）

他流試合ワークショップ（Output）

【組織文化の変革】ナショナルスタッフ主体の体制に向け、必要な組織文化を議論する。

自社への適用視点

次世代リーダーとして、組織をどう牽引し変革するかのアクションプランを描く。

【Day 6】 日程調整中

経営観の統合とリーダーシップ宣言

MBA要素（Input）

ストーリーテリング / 経営観の統合（Synthesis） / 変革のリーダーシップ

他流試合ワークショップ（Output）

【経営者としての所信表明】「私が社長ならこうする」。全回の学びを統合したビジョンと覚悟を宣言する。

自社への適用視点

単なる業務改善案ではなく、未来を担う経営者として「志」と「コミットメント」を示す。

【個社別オプションについて】

Day 6終了後に、貴社独自のオプションとして社内向けの「自社変革提案報告会（Day 7）」を別途設けることも可能です。
また、実施内容や受講者の取り組み姿勢については、後日、企画者様へ簡易報告をさせていただきます。
